# Class Management System

A responsive, feature-rich web application built with HTML5, Tailwind CSS, Chart.js, and vanilla JavaScript.

## Features Included:
- **Authentication / Login Screen**: Role selector (Student / Teacher), password visibility toggle, remember me, quick demo logins.
- **Student Dashboard**: 4 key academic metrics, real-time today's classes timeline, recent announcements, quick links.
- **Interactive Timetable**: 5-day weekly schedule matrix matching course color codes, week switcher, class topic detail modal.
- **Attendance Tracker**: Subject-wise percentage table with color status badges, month/subject filters, and leave application request modal.
- **Assignments Center**: Filterable tabs (All, Upcoming, Submitted, Graded), assignment detail preview, and submission modal with file upload simulation.
- **Grades & GPA**: Semester selector, internal/external marks breakdown table, and transcript download action.
- **Teacher Dashboard & Roster**: Class schedules, pending task manager (marking roll, grading, queries), full student roster with Add, Edit, Delete modals and Active/Inactive status toggle.
- **Teacher Analytics & Reports**: Live Chart.js subject attendance bar chart and department summary statistics.
- **Course Study Materials**: Subject folders and note download actions.
